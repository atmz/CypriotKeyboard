# Greeklish corpus for run_corpus.py
#
# One sentence per line. Comments start with '#'.
# Inputs are intentionally written the way real users type — accents dropped,
# inconsistent transliteration, occasional English words mixed in, Cypriot
# dialect markers (τζ̆/sh, εν, εν να, τζαι, …) where labelled.
#
# Sources & provenance are noted in '###' section headers. When a sample was
# transliterated from Greek script the source line shows '(from Greek)'; when
# it was already in Greeklish online it's marked '(organic)'.
#
# Add new sections for new sources rather than mixing them in randomly — it
# makes regression spotting easier when the eval output drifts.
