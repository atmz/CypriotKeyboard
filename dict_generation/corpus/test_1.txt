

Γνωστό misconception. Αγαπητή μου φίλη. Δεν ησυχάζεις μόλις γεννήσεις. Μόλις γεννήσεις ξεκινά το καλό.
 
Να ξεκαθαρίσω ξεκινώντας ότι είμαι που τζιείντες μισησμένες που είχαν εγκυμοσύνες ζάχαρη. Ούτε εμετούς, ούτε επιπλοκές, ούτε τίποτε. Αν εξαιρέσεις δηλαδή τες ορμόνες που χτυπούσαν κόκκινο τζιαι επροκαλούσαν μου κλάμα για τους ηλιθιοδέστερους δυνατούς λόγους, η εγκυμοσύνη μου ήταν που τες πιο ήρεμες τζιαι στρωμένες φάσεις της ζωής μου. Οπόταν τίποτε εν εμπορούσε να με προετοιμάσει για την καταιγίδα που έρκετουν. Φαντάζομαι για όσες είχαν δύσκολες εγκυμοσύνες, το τέλος της κύησης ήταν μια 'άλφα' ανακούφιση αλλά σίουρα, εν ησυχάσαν.
 
Το τελευταίο τρίμηνο έπιανα τον εαυτό μου να παραπονιέται. Όι γιατί εβάρεσα, όι γιατί εν εβολεύκουμουν να τζιοιμηθω - γενικά εδυσκόλεψε το πράμα. Εκ των υστέρων βέβαια, εν πολλές φορές που ενοστάλγησα τες σύντομες διακοπές του ύπνου για να αλλάξω πλευρό ή να πάω γλήορα - γλήορα τουαλέτα. Γιατί όταν ήρταν τα γιούθκια μου, με λλία λόγια, αλλάξαν μου τα φώτα.
 
Τον όρο "τέταρτο τρίμηνο" είδα τον σε ένα μαμαδογκρουπ στο facebook όταν ήταν ήδη αρκετά αργά. Όταν τζιείνη η φάση επέρασε για μένα, αλλά ο όρος ήρτε για να εξηγήσει ούλλα όσα που εβίωνα με ένα απόλυτα λογικό τζιαι φυσιολογικό τρόπο. Σίουρα πολλά πιο καλό που επεξηγήσεις τζιαι φράσεις του στυλ, " Εν να τον κακομάθεις", "έγινε σιυλλούι", "άηστον να κλάψει να ανοίξουν τα πνευμόνια του" που άκουα που παππούδες, γιαγιάδες και λοιπούς συγγενείς.
 
Τέταρτο τρίμηνο γιατί; Γιατί ουσιαστικά το μωρό συνεχίζει να είναι κομμάτι σου για τουλάχιστον ένα τρίμηνο μετά τη γέννα. Γιατί τους πρώτους τρεις μήνες της ζωής του, εν να'ναι ούλλα τόσο καινούρια για τζιείνο, που εν να χρειαστεί λλίο πολλά να είναι συνέχεια προσκολλημένο πάνω σου για να μπορέσει να αντεπεξέλθει στο καινούριο περιβάλλον. Γιατί μπορεί να μεν εν μέσα στην κοιλιά σου, αλλά εν ναν τόσο κολλημένο πάνω σου, που εν σαν να το κουβαλάς ακόμα.
 
Τι να περιμένετε το τέταρτο τρίμηνο, λοιπόν, τζιαι πως αντιμετωπίζεται παρακάτω.
1. Πάρτι ορμονών.
Όι, επειδή ετέλειωσε η εγκυμοσύνη εν σημαίνει ότι ελείψαν οι ορμόνες. Αντίθετα. Μετά τη γέννα, ο οργανισμός σας εν να σαν να εμπήκε σε ρόλερ κόστερ τζιαι εχάλασε το off button. Εν να αντιδράς με τρόπους που εν καταλαβαίνεις, αν να λαλείς πράματα που εν τα εννοείς. Ε, τζιαι σε συνδυασμό με την αϋπνία τζιαι την κούραση, ε εν τζιαι θέλει τζιαι πολλά το πλάσμα να ταράξει.
Αντιμετώπιση: Μίλα. Κλάψε. Ξέσπα. Πε τα. Τζιαι εν να περάσει. Τζιαι αν δεν περάσει, εν να βρεις τρόπο να το θκιώξεις εσύ.
 
2. Κλάμα ο (νεογέννητος) λαός. 
Πολλύ κλάμα. Κλάμα για πείνα. Κλάμα για νύστα. Κλάμα για πόνο. Κλάμα για άλλαμα. Κλάμα για υπερδιέγερση. Κλάμα χωρίς κανένα απολύτως προφανή λόγο. Τα μωρά κλαιν, γιατί έτσι εν η κατασκευή τους.
Αντιμετώπιση: Υπομονή τζιαι εκλογίκευση. ΕΝ ΦΤΑΕΙΣ για κάθε ιδιοτροπία, εν μπορείς να σταματήσεις κάθε δάκρυ. Τζιαι ναι, εν να φτάσεις τζιαι σε φάση που εν να σπάσουν τα νεύρα σου τζιαι εν να αφήκεις το μωρό να κλάψει τζιαι 2 λεπτά μες το κρεβάτι του γιατί θέλεις να πάρεις λλίο αέρα. Εν εντάξει. Εν σε κάμνει κακή μάνα τούτο.
 
3. Ακόμα φαίνεσαι έγκυος.
Τζιαι το mummy pouch is here to stay. Δεν επανέρχεται το σώμα στα φυσιολογικά για μήνες. Μεν σε αγχώνει. Θα βάλεις τα ρούχα της εγκυμοσύνης για όσο χρειαστεί. Τζιαι όταν έρτει η ώρα, θα κάμεις ότι θέλεις τζιαι μπορείς για να νιώσεις ξανά καλά.
Αντιμετώπιση: Θήλασε! Ναι, ναι, καλά εθκιέβασες! Ο θηλασμός καίει θερμίδες, τζιαι πολλές μάλιστα. Οπόταν με το θηλασμό θα επανέλθεις στο φυσιολογικό σου βάρος (περίπου) ακόμα πιο σύντομα.
 
4. Προσκόλληση. 
Θα θέλει κρατήδι. Όι επειδή εν "κακό" το μωρό ή επειδή εκακομάθετε το, αλλά επειδή εν ΦΥΣΙΚΟ να θέλει το μωρό τη μάμα του. Σε ένα κόσμο γεμάτο καινούρια ερεθίσματα νιώθει τρομερή ανασφάλεια. Η ασφάλειά του είσαι εσύ, γιατί απλά εσύ ΉΣΟΥΝ το σπίτι του για τους προηγούμενους 9 μήνες. Αν προσπαθείς να το κάμεις "ανεξάρτητο" που τόσο νωρίς, τζιαι το μωρό θα ταλαιπωρήσεις, τζιαι εσύ θα ματαιωθείς που εν θα το πετυχαίνεις.
Αντιμετώπιση: Κράτα το μωρό! Φόρησ'το σε μάρσιπο. Αγκάλιασ'το τζιαι τζιοιμήθου μαζί του. Βασικά προσποιήθου για λλίο ότι είσαι καγκουρό. Άηστο μωρό μες την κοιλιά σου ώσπου να εν έτοιμο να σε αποχωριστεί. Αποδέχτου την κατάσταση για να γλιτώσεις κλάμα,  τζιαι πολλά νεύρα.
 
5. Θα έχεις ανασφάλεια.
Για τα ΠΑΝΤΑ. Πυρώνει; Κρυώνει; Τρώει; Πονεί; Βαρκέται; Εν άρρωστο; Εν να σου μπαίνουν συνέχεια ιδέες για τα πάντα. Όι επειδή είσαι πελλή. (Αν τζιαι πιστεύκω ότι μια δόση σχιζοφρένειας εν μες το job description της μητρότητας). Αλλά επειδή τζιείντο μικρό, απροστάτευτο πλάσμα που έσιεις μπροστά σου εν δική σου ευθύνη τζιαι φοάσαι ότι κάτι εν να σου "φύει" τζιαι το μωρό εν να κινδυνεύσει.
Αντιμετώπιση: Αν πραγματικά ανησυχείς, μίλα με τον γιατρό σου. Καλλύττερα να σε φκάλει ττακκουρημένη, παρά να σε τρων οι έγνοιες τζιαι οι σκέψεις. 
 
6. Εν θα ταράσσεις
Όι επειδή εν θα θέλεις. Αλλά επειδή εν να καταλάβεις ότι ήταν πολλά ευκολόττερο να κυκλοφοράς με +20 κιλά τζιαι ένα μωρό μες την τζιοιλιά σου, παρά να κρατάς ένα μωρό τζιαι ούλλα του τα υπάρχοντα τζιαι να κυκλοφοράς. Car seat, αμαξού, τσέντες τζιαι τσεντούθκια, κουβέρτες, πανιά, μαντηλάκια... Τζιαι να μεν ξέρεις τζιαι πως εν να αντιδράσει το μωρό - οι πιθανότητες να σου την φκάλει που τη μούττη την έξοδο εν αυξημένες!
Αντιμετώπιση: Εν να μπεις στον πειρασμό να κλειδωθείς σπίτι. Ζήτα ενισχύσεις, τζιαι κυκλοφόρα. Δοκίμασε. Εν να σου κάμει καλό. Trust me.
 
Γενικά, τζιείνο που με βοήθησε με το δεύτερο μωρό να αποφύγω πολλά που τα αρνητικά συναισθήματα που έζησα με το πρώτο, ήταν η αποδοχή. Έξερα τι να περιμένω, αποφάσισα πως θα το αντιμετωπίσω αλλά άφηνα πάντα περιθώριο για συναισθήματα απελπισίας τζιαι στιγμές που θα χρειάζουμουν mental breaks. Προφανώς ένεν ούλλα ιδανικά, αλλά εν καλλύττερα. Τζιαι ναι, μετά το τέταρτο τρίμηνο, μπορεί να έρτει τζιαι πέμπτο, αλλά τα πράματα σάζουν τελικά. Τι; Όι;
